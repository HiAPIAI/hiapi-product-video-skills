# Legacy install compatibility

```bash
npx -y github:HiAPIAI/hiapi-seedance-2-0-ugc-ad-video-skill -y
```

The command installs the `ugc-ad` adapter into its historical
`hiapi-seedance-2-0-ugc-ad-video-skill` folder. The unified command is:

```bash
npx -y github:HiAPIAI/hiapi-product-video-skills -y --adapter ugc-ad
```
