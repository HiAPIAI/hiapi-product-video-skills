Source: `hiapi-fashion-lookbook-video-skill`.

Owns runway/lookbook recipes, person/garment/style media roles, source order,
asset rights, person consent, fictional-fit disclaimers, and Kling versus

The adapter must call the shared runner for price lookup, spend gating,
request hashing, retries, polling, output download, and QC artifact writing.
